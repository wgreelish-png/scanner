# One standard market pricing source

Build 27 uses the TCGTracking public Open API for every production market quote: live-scan confirmation, cached catalog additions, saved-card editing/correction and public Market Details. The standard provider accepts no legacy provider or provider-selection closure. Old `marketPricingSource` defaults are ignored, including a saved `tcgtracking` choice. Opening the app does not rewrite any saved inventory, manual market value, price metadata, offer, session or schema.

Settings displays Market pricing: Open API as information. Provider selectors are removed from Settings, scanner Options, scan confirmation and manual additions; compact Card Details already removed its selector in build 26. Selecting a condition, printing or language still obtains the exact returned SKU quote. Zero stays a known price; missing prices stay unavailable, and unsupported cards can be saved unpriced or assigned an explicit manual market value where supported.

The scanner starts without a website-price sign-in step. Open API quote failures never fall back to the website or ask for website sign-in. Account sign-in remains explicitly available through Settings and scanner Options, with its existing Keychain/session behavior for account features and Beta IP access. Returning from account sign-in no longer initializes or invalidates the old public website-pricing browser. Graded Research, OppsV2 access methods and Beta credentials remain separate.

Existing Open API transport, exact product/set resolution, condition/printing/language matching, daily freshness, manual force-refresh, bounded four-set cache, offline labels and original provider timestamps are retained. No data is downloaded from every game in bulk, no background mode is added, and no synthetic condition discount is introduced. Public errors preserve the selection and permit retry; provider/source settings cannot redirect a request after it starts.

The old `tcgtracking` Codable source case is retained for historical saved price provenance. Its label/date are not changed to Open API. Legacy response parsers/transport fixtures remain compatible, but no production pricing entry point constructs, prepares or requests their website browser. An existing saved card keeps its price on opening; refreshing or changing its exact identity obtains a new public quote in the draft, and Save explicitly commits it.

## Validation

Implementation, UI removals, compatibility handling, documentation and version updates finish before checks begin. Native cases cover ignored legacy/invalid preferences, original metadata decoding, preparation/identity/candidate forwarding, missing/zero values, provider failures without retries/fallback, cached timestamps, a legacy preference change during an in-flight public request, cancellation and explicit refresh. Existing scanner/editor integration and cache cases continue to cover frozen selections, late replies, separate rows and saved-data isolation. The Settings UI case checks a read-only Open API label across relaunch with a legacy launch preference.

On an iPhone, upgrade over the existing installation, open an old card without refreshing and confirm its stored price/offer is intact. Refresh and test condition/printing changes in scanner, manual addition and Card Details. Confirm no provider picker or pricing sign-in prompt appears. Exercise a previously cached exact quote offline and check its original date. Confirm explicit TCGTracking account sign-in, Beta IP access and API connections still work independently. Xcode/native execution and these physical-device checks must be reported separately from static checks.
